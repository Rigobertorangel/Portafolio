Sistema de Gestión de Mantenimiento para Estufas Industriales

Desarrollé un sistema de escritorio en consola utilizando Java para la gestión de clientes, técnicos, usuarios y servicios de mantenimiento de estufas industriales. La aplicación implementa operaciones CRUD (Crear, Leer, Actualizar y Eliminar) y utiliza MySQL como sistema de gestión de bases de datos para almacenar y administrar la información de forma centralizada. El proyecto fue desarrollado aplicando Programación Orientada a Objetos (POO), separación por capas y conexión a bases de datos mediante JDBC, permitiendo automatizar el registro, consulta y seguimiento de los servicios realizados.

Menú Principal

Panel principal del sistema que centraliza el acceso a los módulos de Clientes, Servicios, Usuarios y Técnicos, además de permitir salir de la aplicación.

Resultado: Se logró una navegación organizada e intuitiva que facilita el acceso a todas las funcionalidades del sistema, reduciendo el tiempo de operación y mejorando la experiencia del usuario.

Módulo de Clientes

Permite registrar, modificar, eliminar, listar y buscar clientes mediante operaciones CRUD. Además administra información personal, direcciones y tipo de cliente (empresa o particular).

Resultado: Se centralizó toda la información de los clientes, facilitando su consulta y actualización, reduciendo errores en el registro y agilizando la búsqueda de datos mediante diferentes criterios.

Módulo de Servicios

Administra los servicios de mantenimiento y reparación permitiendo registrar, modificar, eliminar y consultar la información de cada servicio realizado, incluyendo costo, fecha y tipo de mantenimiento.

Resultado: Se obtuvo un historial organizado de los mantenimientos realizados, permitiendo controlar costos, fechas y tipos de servicio, mejorando el seguimiento de cada intervención técnica.

Módulo de Usuarios

Gestiona las cuentas del sistema permitiendo registrar, consultar, editar, eliminar y visualizar usuarios, además de controlar el estado de acceso de cada uno.

Resultado: Se implementó un control de acceso seguro que facilita la administración de usuarios autorizados, permitiendo mantener actualizadas las credenciales y restringir el acceso cuando sea necesario.

Módulo de Técnicos

Permite registrar, modificar y consultar la información de los técnicos responsables de realizar los mantenimientos y reparaciones de estufas industriales.

Resultado: Se organizó la información del personal técnico, facilitando su administración y permitiendo identificar rápidamente a los responsables de cada servicio realizado.

Listado de Servicios

Muestra el historial completo de los servicios registrados, incluyendo cliente, técnico responsable, tipo de servicio, fecha y costo de cada mantenimiento realizado.

Resultado: Se facilitó la consulta del historial de mantenimientos, permitiendo realizar un seguimiento eficiente de los servicios ejecutados y mejorar el control de la información almacenada en la base de datos.

Descripción General del Proyecto

Resumen

El desarrollo del sistema permitió automatizar la gestión de clientes, técnicos, usuarios y servicios de mantenimiento de estufas industriales mediante una aplicación de consola desarrollada en Java. Gracias a la implementación de una arquitectura modular y el uso de una base de datos relacional, se logró una solución organizada, escalable y de fácil mantenimiento.

  • Se implementó una base de datos relacional en MySQL, administrada mediante WampServer, garantizando el almacenamiento seguro y persistente de la información.
  • Se estableció la conexión entre Java y MySQL utilizando JDBC, permitiendo realizar operaciones de consulta y actualización de datos de manera eficiente.
  • Se desarrollaron operaciones CRUD (Crear, Leer, Actualizar y Eliminar) para los módulos de Clientes, Técnicos, Usuarios y Servicios.
  • Se aplicó el paradigma de Programación Orientada a Objetos (POO), utilizando clases, encapsulamiento y separación por capas para mejorar la organización del código.
  • Se implementó un sistema de autenticación mediante usuario y contraseña para controlar el acceso a la aplicación.
  • Se incorporaron validaciones de entrada para evitar errores durante el registro de información y mejorar la estabilidad del sistema.
  • Se optimizó la administración de los servicios de mantenimiento mediante la consulta, modificación y seguimiento del historial de servicios realizados.
  • Se redujo el tiempo de búsqueda de información gracias a las funciones de consulta y filtrado implementadas en los diferentes módulos.
  • Se logró una estructura modular que facilita futuras mejoras y la incorporación de nuevas funcionalidades.

    • El proyecto permitió fortalecer conocimientos en desarrollo de aplicaciones Java, conexión con bases de datos MySQL, consultas SQL, manejo de JDBC y organización del software mediante una arquitectura por capas.
